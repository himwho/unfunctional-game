# Credits and attribution inventory

The in-game ending now links to skippable credits and a paginated license-notice viewer.
Creator credit is **The Unfunctional Team**. No individual role or ownership is inferred from a Git username.

## Sources included in credits

Package names come from local `.meta` AssetOrigin records: Jungle – Tropical Vegetation,
SeedMesh vegetation shaders, Modern LED Lighting Pack, Keypad FREE, 8K Skybox Pack Free,
FREE Skyboxes – Space, VHS UI Effect, Mirrors and reflections for VR, and Pro Glass Shader.
Publisher labels are used only where the installed folder names identify them: SeedMesh,
PolyKebap, Turishader, Fragilem17, and Singular Bear. Unity, URP, TextMesh Pro, and Polybrush
are acknowledged separately.

## Font notices

Original license text is included under `Assets/Resources/GameArt/Notices` and paginated,
without omitting terms, in the in-game viewer:

- Liberation Sans: existing project OFL notice, including Google and Red Hat copyright lines.
- Caveat: [Google Fonts source license](https://github.com/google/fonts/blob/main/ofl/caveat/OFL.txt).
- Staatliches: [Google Fonts source license](https://github.com/google/fonts/blob/main/ofl/staatliches/OFL.txt).
- Open Sans: existing project Apache 2.0 notice.
- Roboto: existing project Apache 2.0 notice.

The new shaped shovel mesh is generated by `CampaignArtBaker`; it reuses the project's
wood and metal materials. The achievement room reuses project tile, concrete, door, and
keypad success audio as a fallback. The current art pass adds five code-generated award sounds
and a code-generated shovel crack, plus code-generated UI sprites and meshes. No new external
art pack or music was added.

ShopProducts.png is a generated 4×5 product-art atlas made with the built-in image generation
tool. The exact prompt and approved environment concept board are retained under
reference-design/concepts. DepartmentProps builds new scenic models using existing project
materials. See ART_IMPLEMENTATION.md for asset locations.

## Release verification still needed

This is an attribution inventory, not proof of asset purchase or a license clearance.
Verify entitlement and redistribution terms for Asset Store packages before shipping.
The provenance of loose files in `Assets/Art`, the Doors package, and the legacy Unipix
font is not documented in the checkout. Retain source/purchase records, identify any
required creator credits, and confirm which assets are included in the final player build.
Do not invent an author or license for those files. Bundled demo assets are acknowledged
conservatively here; remove unused dependencies only after checking the build report.
